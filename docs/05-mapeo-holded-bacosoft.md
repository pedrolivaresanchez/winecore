## 4. Lecciones para el diseño (de la integración Bacosoft ↔ Holded)
1. El lote debe ser entidad propia (Holded no deja crear lotes por API y no impide duplicados).
2. Una sola fuente de verdad para el stock (las correcciones manuales en Holded no volvían a Bacosoft).
3. Identificadores externos desde el primer día para migrar y conciliar.
4. Editar un movimiento ya declarado debe **anular y reemplazar** los asientos afectados (SILICIE) y avisar si hay que pedir la modificación de una declaración ya presentada (INFOVI).
